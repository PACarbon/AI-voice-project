# 触摸屏口控制

在linux下，一切都是文件。连触摸屏都是文件。
触摸屏设备路径：`/dev/input/event0`

## 读取触摸屏幕的文件信息

```c
#include <stdio.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <string.h>
#include <sys/mman.h>

int main()
{
    // 1. 打开触摸屏
    int tfd = open("/dev/input/event0", O_RDONLY);
    if (tfd == -1)
    {
        perror("open /dev/input/event0 failed! \n");
        return -1;
    }

    printf("打开触摸屏成功! \n");

    // 触摸屏的数据什么时候写入是不确定的，因为我们无法预知用户什么时候触摸开发板
    // 为了能够读取到用户触摸数据，我们必须要写个死循环不断的读取触摸屏的数据

    // 先不考虑触摸屏到底写的数据是什么数据结构，以普通字符类型来读取
    char buf[50];
    while (1)
    {
       // 每次读取数据清空下buf
       bzero(buf, 50);
       read(tfd, buf, 50);
       printf("%s\n", buf);
    }
    

    close(tfd);
    
}
```
